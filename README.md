# FNS Receipt Parser

Локальный Python-скрипт для экспорта чеков из сервиса ФНС «Мои чеки онлайн» (`lkdr.nalog.ru`).

Проект сохраняет список чеков, получает фискальные данные по каждому чеку и формирует удобные JSON/CSV-файлы для последующего анализа личных расходов.

> Проект не является официальным продуктом ФНС России и не связан с ФНС. Он использует интерфейсы, доступные авторизованному пользователю сервиса.

## Возможности

- загрузка списка чеков из «Мои чеки онлайн»;
- получение состава каждого чека;
- полный экспорт данных в JSON;
- сводная таблица чеков в CSV;
- отдельная CSV-таблица со всеми товарными позициями;
- сохранение ошибок отдельных чеков без остановки всей выгрузки;
- Bearer token вводится скрыто в терминале и не записывается на диск.

## Требования

- Python 3.9+;
- доступ к `https://lkdr.nalog.ru`;
- действующий Bearer token авторизованной сессии пользователя.

В текущей версии внешние Python-зависимости отсутствуют: используются только модули стандартной библиотеки.

## Запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/TumanovNV/fns-receipt-parser.git
cd fns-receipt-parser
```

Запустите:

```bash
python3 export_nalog_receipts.py
```

Скрипт запросит Bearer token:

```text
Вставьте Bearer token:
```

Ввод в терминале скрыт. Токен не сохраняется в файлы проекта.

## Результат

После завершения создаётся каталог:

```text
nalog_receipts_export/
├── receipts_full.json
├── receipts_summary.csv
├── receipt_items.csv
└── errors.json          # только если были ошибки
```

### `receipts_full.json`

Полные данные списка чеков вместе с полученной детализацией.

### `receipts_summary.csv`

Одна строка на один чек: продавец, ИНН, дата, сумма, фискальные реквизиты и статус детализации.

### `receipt_items.csv`

Одна строка на одну позицию внутри чека: наименование, цена, количество, сумма, НДС и другие доступные поля.

CSV создаются в кодировке UTF-8 с BOM и с разделителем `;`, что удобно для открытия в Excel.

## Безопасность

Никогда не публикуйте:

- Bearer token;
- cookies авторизованной сессии;
- реальные выгрузки чеков;
- персональные данные из чеков.

Каталог `nalog_receipts_export/`, `.env`, CSV и JSON-файлы исключены через `.gitignore`.
